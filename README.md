# NMF — Natya Meets Fitness

> **Original Concept & Prototype:** Designed by me as an original project blending classical Indian dance with structured fitness routines.

---

## 📌 Project Overview

**Natya Meets Fitness (NMF)** is an innovative mobile application concept that bridges traditional Indian classical dance movements with modern physical fitness training. The platform reimagines classical dance modules into accessible, goal-oriented workout routines.

## 📱 Features & Screen Breakdown

1. **Authentication (Login Screen):** User authentication interface featuring standard credentials entry and Google Single Sign-On (SSO).
2. **Dashboard / Home:** Workout categories mapped directly to dance components:
   * **Adavus** — Core Exercises
   * **Charis** — Cardio Exercises
   * **Jathis** — Muscular Exercises
   * **Karanas** — Flexibility & Balance Exercises
3. **User Profile:** Personal settings, saved favorite workouts, language selection, and user feedback mechanisms.
4. **Exercise Module (Adavus Breakdown):** Specialized listings covering foundational movements including Tatta Adavu, Natta Adavu, Tatti Metti Adavu, and Kudittu Metti Adavu.
